# Factory Reallocation & Shipping Optimization Using Machine Learning

## Overview
This project focuses on optimizing factory allocation and shipping operations using machine learning, recommendation systems, and dashboard analytics.

The project analyzes lead time, sales, profitability, and operational performance using the Nassau Candy Distributor dataset.

---

## Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Lead time analysis
- Machine learning prediction
- Recommendation system
- Streamlit dashboard
- Business optimization insights

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- Google Colab

---

## Machine Learning Models
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

---

## Dashboard Features
- Region filters
- Ship mode filters
- KPI metrics
- Recommendation system
- Lead time analysis
- Sales analysis

---

## Recommendation Logic
- High lead time → Recommend Faster Factory
- Low lead time → Current Factory Efficient
